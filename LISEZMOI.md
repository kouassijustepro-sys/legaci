# legaci-atelier — l'atelier de montage du Trait

Ce dossier va dans Claude Code. Il fabrique les vidéos du Trait dans la direction artistique « Atlas de papier ».

## Pour commencer
1. Décompresse le dossier sur ton ordinateur.
2. Ouvre-le dans Claude Code.
3. Écris : « Installe ce qu'il faut pour l'atelier, puis monte le Trait 003 et montre-moi un aperçu. »

## Ce qu'il y a dedans
- `CLAUDE.md` : la mémoire de l'atelier (règles, charte, formats, commandes). Claude Code la lit tout seul.
- `.claude/agents/` : le Monteur, l'Ingénieur du son, le Contrôleur technique.
- `.claude/skills/monter-un-trait/` : la procédure de la fiche à la vidéo.
- `atelier/atlas.js` : les outils de dessin (papier, déchirures, trame, encre, Dymo, route, point braise).
- `atelier/gabarits/f3_collage.html` : le format F3, prêt.
- `atelier/scenes/003_yao_1.json` : l'exemple « Le cas de Yao 1/4 ».
- `atelier/render.py`, `apercu.py`, `controle.py` : rendu, aperçu, contrôle.
- `atelier/rendus/003/` : le prototype déjà rendu.
- `banque/` : les 8 dossiers de ta banque visuelle, vides, à remplir avec tes photos et tes sons.

## À remplacer dans le prototype
- La main dessinée → ta photo de main détourée (`banque/03_mains/`).
- Yao en silhouette → silhouette découpée dans une photo d'un modèle qui a signé un accord, ou dessin d'un artiste.
- Les bruitages provisoires → les vrais sons de la banque et la signature sonore du beatmaker.
- Ajouter la voix.

Polices incluses : League Spartan, Big Shoulders Display, Reenie Beanie, Special Elite (Google Fonts, licences libres à relire une fois sur leur page).
